# LamprosDAO College Session Reports

Analysis and visuals of LamprosDAO college session feedback and participation. Contains student-level data: keep private or anonymize before publishing.

## Structure

- `data/`
- `notebooks/`
- `outputs/`

## Privacy note

The CSV files under `data/` contain student-level information (college, gender, wallet/account activity). Keep this repository **private** or anonymize the data before making it public.
